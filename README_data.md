# Data

The input files are course materials and are **not included** in this repository. To run the
notebooks, place these 9 files in the folders below (names exactly as shown).

| File | Folder | Format | Used by |
|---|---|---|---|
| `coronaviruses_spike.fasta` | `ex1/` | DNA FASTA (spike genes of several coronaviruses) | Exercise 1: Markov model training, alignment |
| `SARS-CoV-2_spike.fasta` | `ex1/` | DNA FASTA (SARS-CoV-2 spike gene) | Exercise 1: alignment reference |
| `NP_001001957.2.faa` | `ex2/` | protein FASTA | Exercise 2: Viterbi decoding / HMM scoring |
| `NP_149420.4.faa` | `ex2/` | protein FASTA | Exercise 2: Viterbi decoding / HMM scoring |
| `WLF82657.1.faa` | `ex2/` | protein FASTA | Exercise 2: Viterbi decoding / HMM scoring |
| `rats_olfactory_receptors.fasta` | `ex2/` | protein FASTA (protein family) | Exercise 2: multiple alignment, profile HMM |
| `drug_combination_responses.csv` | `ex3/` | CSV | Exercise 3: random forest response prediction |
| `gene_expression.csv` | `ex3/` | CSV (cell lines × genes) | Exercise 3: PCA, differential expression |
| `cell_line_metadata.csv` | `ex3/` | CSV (tissue type, TP53 status) | Exercise 3: PCA coloring, design matrix |

```
data/
```

## Not files

- Exercise 1 downloads the SARS-CoV-2 reference genome (GenBank `NC_045512`) at runtime with
  `ape::read.GenBank`, so it needs an internet connection.
- The BLOSUM62 matrix comes from the `Biostrings` package (`data(BLOSUM62)`).

## Generated by the notebooks

`Sars-CoV-2-translated.fasta` (Exercise 1) and `msa_plot.pdf` (Exercise 2) are written to the
working directory when the notebooks run. They are listed in `.gitignore`.

`.gitignore` excludes everything in this folder except this file.
